# «Нұрзат» — kindergarten website

Website for **«Нұрзат»** kindergarten (Kazakhstan). Parents can learn about the kindergarten, its groups and daily routine, see photos and official documents, and leave a request for a place.

Documents are published separately on the [document portal](https://github.com/Zhanserk/Nurzat).

🔗 **Live:** https://www.nurzat-sadikedu.kz/

## Sections

- About the nursery
- Four groups — «Байтерек», «Балапан», «Күншуақ», «Болашақ»
- Daily routine
- Photo gallery — building, rooms, everyday moments
- Official documents
- Contacts with a map and WhatsApp
- Enrollment request

## Tech

React 19 · Vite · JavaScript · CSS · deployed on Vercel · mobile-friendly

## Run locally

```bash
npm install
npm run dev
```
